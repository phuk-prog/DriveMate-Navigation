# Existing DriveMate Android app is the target

DMN is a navigation research and comparison programme, not another standalone phone application. This repository has no DMN APK requirement. Its original C++ router and Python components are test candidates only.

After equivalent engine tests, UK legal-turn validation, device GPS, offline memory/battery and audio/Bluetooth checks, the best legally compatible approach can be proposed for integration into the **existing** `phuk-prog/DriveMate` Android application. No production repository changes are authorised by research runs.
