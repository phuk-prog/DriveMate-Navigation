# DMN research repo — Claude quick start

Run `python3 -m tools.work_status --fetch` (shared register of done / in-progress / next work
for all AIs), read [docs/HANDOVER.md](docs/HANDOVER.md), then follow [AGENTS.md](AGENTS.md).
Keep usage low: one task per session; long runs on GitHub Actions (read the job
summary only); short outputs (`tools/turn001_brief.py`); one AI per branch;
never force-push; no Android app changes; update HANDOVER.md before stopping.
