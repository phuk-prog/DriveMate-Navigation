# DMN owner instruction — no new registration for research evidence

Owner decision, 17 October 2026:

> If it requires any registration, move on and leave it as diagnosed.

**Apply to future DMN research tasks:** Do not sign up, create accounts,
request credentials, buy subscriptions or seek account access to complete a
benchmark, data lookup or independent road-law check. If the required source
cannot be obtained using the project's existing lawful, accessible tools,
leave the item **DIAGNOSED / UNVERIFIED** with an exact source/access reason
and move to another unblocked research task. Do not repeatedly retry the
same registration-dependent source or ask the owner to register.

This rule is about workflow and evidence availability, **not driving
legality**. Never change routing/turn/access decisions solely because
the confirming source is unavailable. Preserve frozen test results and
separate OSM/map-derived judgments from independently verified road truth.
